| **`NETWORK` ReferenceError in browser** | `js/app.js` uses `NETWORK_DATA` (global from `preview_data.js`) instead of undefined `NETWORK`. |

| **Provenance labels only on St. John's** | All 6 hospitals now carry `SYNTHETIC_DROP_OFF` on `bay_a`, `bay_b`, `driveway` (18 labels total). |
| **Topology audit** | 35 nodes / 63 edges; 4 undirected components (sizes `[32,1,1,1]`); 3 isolated nodes (`node_mg_road`, `node_shivajinagar`, `node_victoria_hospital_main`) — documented as declared-but-unwired / by-design; genuine alternate corridor (Seshadri bypass) verified; Victoria ingress is single-path choke. |
| **Duplicate-vehicle bug in `_moveToEdge`** | Root cause: failure branch re-enqueued vehicle into `oldQueue` even though never removed during traversal. Fix: removed spurious `oldQueue.enqueue(veh)` line. Verified by test 6b (3 ambulances / 2 bays, 12k ticks, no deadlock, all trips complete). |

### Neutral & Negative Findings (Preserved Intentionally)

- **Tier-2 signal priority yields zero ambulance benefit on `peak_signalised_corridor`** — A = B = C = D at 400.6 s despite C/D firing 3 interventions. Preemptions are real and verified; they simply do not shorten this trip. Reported as-is.
- **Mode B equals Mode A on `mild_congestion_below_threshold`** — genuine slowdown, no reroute. The honesty control holds: router correctly does not claim a win that did not happen.
- **Mode C is no better than A on heavily congested scenarios** (both DNF). Signal priority alone does not rescue a blocked corridor; only rerouting does.
- **A DNF is a first-class reported outcome**, never silently dropped.
